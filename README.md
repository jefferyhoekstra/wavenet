# WaveNet Blogsite

A full-stack blog website built with **React + Vite & Node.js Express**, showcasing my projects, skills, and experience as a developer.

🌐 **Live site:** https://wavenet-ten.vercel.app
📂 **Repository:** https://github.com/jefferyhoekstra/wavenet

---

## 🚀 Tech Stack

- **Framework:** React, Express
- **Build Tool:** Vite, Node.js
- **Languages:** HTML, CSS, JavaScript (JSX)
- **Styling:** CSS
- **Deployment:** Vercel.app

---

## ✨ Features

- Responsive layout for desktop and mobile
- Uses cookies, JWT-Authorization
- Clean, minimal design focused on clarity and usability

---

## 🛠️ Getting Started

To run the project locally:

```bash
git clone https://github.com/jefferyhoekstra/wavenet.git
cd frontend
npm install
npm run dev
cd ..
cd backend
npm install
npm --watch start
